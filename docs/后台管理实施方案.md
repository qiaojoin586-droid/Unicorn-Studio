## 3. 后台 API 全量清单

约定：`/api/admin/**` 全部走 `@Order(1)` 认证链 + `@PreAuthorize`；返回统一信封；写接口记审计。

### 3.1 认证

| 方法/路径 | 请求 | 响应 data | 权限/限流 |
|---|---|---|---|
| POST `/api/admin/auth/login` | `{username, password}` | `{accessToken, refreshToken, expiresIn:7200}` | 公开；IP 5次/分，账号失败5次锁30分钟 |
| POST `/api/admin/auth/refresh` | `{refreshToken}` | `{accessToken, refreshToken}`（旧 refresh 作废） | 公开；限流同登录 |
| POST `/api/admin/auth/logout` | Bearer | `null`（服务端删除 refreshToken） | 已登录 |
| GET `/api/admin/auth/me` | Bearer | `{id, username, nickname, avatar, roles:[{code,name}], permissions:[code...]}` | 已登录 |

### 3.2 仪表盘

| 方法/路径 | 请求 | 响应 data | 权限 |

## 5. 关键实现要点（代码级）

### 5.1 双过滤器链（后端）

```java
@Configuration
@EnableWebSecurity
@EnableMethodSecurity   // 开启 @PreAuthorize
public class AdminSecurityConfig {

    @Bean
    @Order(1)  // 后台管理链：/api/admin/**
    public SecurityFilterChain adminChain(HttpSecurity http, JwtAuthFilter jwtFilter) throws Exception {
        http.securityMatcher("/api/admin/**")
            .csrf(csrf -> csrf.disable())
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth.anyRequest().authenticated())
            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class)
            .exceptionHandling(e -> e
                .authenticationEntryPoint((req, res, ex) ->
                    writeJson(res, 401, 40100, "未认证或登录已过期"))
                .accessDeniedHandler((req, res, ex) ->
                    writeJson(res, 403, 40300, "无操作权限")));
        return http.build();
    }

    @Bean
    @Order(2)  // 公开链：/api/**（含 stats/pv、前台注册等，各接口自带限流）
    public SecurityFilterChain publicChain(HttpSecurity http) throws Exception {
        http.securityMatcher("/api/**")
            .csrf(csrf -> csrf.disable())
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth.anyRequest().permitAll());
        return http.build();
    }
}
```

要点：
- 401/403 统一返回 `ApiResponse` 信封（`{code:40100, message, data:null}`），前端拦截器据此触发刷新或跳登录；
- JWT 过滤器从 `Authorization: Bearer` 解析 → 查库加载角色/权限（**实时**，角色修改即时生效）→ 注入 `UsernamePasswordAuthenticationToken(principal, null, authorities)`；
- `SUPER_ADMIN` 角色代码级绕过：`@PreAuthorize` 判定逻辑为 `hasRole('SUPER_ADMIN') or hasAuthority('xxx')`——用自定义 `PermissionEvaluator` 或在加载 authorities 时对该角色注入全部权限码（**推荐后者**，注解写法不变：加载时若含 SUPER_ADMIN 则 authorities = 全量权限码集合）。

public @interface AuditLog { String module(); String action(); }

@Aspect @Component
public class AuditLogAspect {
    @Around("@annotation(auditLog)")
    public Object around(ProceedingJoinPoint pjp, AuditLog auditLog) throws Throwable {
        long start = System.currentTimeMillis();
        try {
            Object result = pjp.proceed();
            save(pjp, auditLog, "success", null, System.currentTimeMillis() - start);
            return result;
        } catch (Throwable t) {
            save(pjp, auditLog, "failed", t.getMessage(), System.currentTimeMillis() - start);
            throw t;
        }
    }
    // save: 参数 JSON 序列化后脱敏（password/token/refreshToken → "***"）、IP、耗时
    // 写入用 @Async，不拖慢业务响应
}
