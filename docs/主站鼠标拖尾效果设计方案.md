## 1. 需求定义

鼠标移动时，光标后方跟随一串逐渐消散的视觉元素（圆点 / 星星 / 线条 / 粒子），形似"扫把拖尾"，约 0.5–1 秒内完全消失。

**设计目标（按优先级）：**

1. **不干扰**：纯装饰层，`pointer-events: none`，绝不影响点击、拖拽、选字、悬停等任何交互；
2. **不卡顿**：rAF 满帧率跟手（60/120/144Hz），dt 归一化保证各刷新率下观感一致，无 GC 抖动，空闲时零 CPU 开销（不出帧）；
3. **有品位**：贴合站点深色梦幻主题（indigo/purple 渐变、🦄 品牌），低透明度、快速消散，是"彩蛋"而非"干扰"；
4. **有分寸**：尊重系统设置——`prefers-reduced-motion` 用户完全无感；触屏设备自动关闭；管理端不受影响。

### 1.1 拖尾形态选型

| 形态 | 效果描述 | 与站点气质的契合度 | 实现复杂度 | 结论 |
|---|---|---|---|---|
| A. 星尘粒子（推荐） | 混合小圆点光斑与四角星芒，随机大小/色彩/闪烁，带轻微上浮，加法混合发光 | ★★★ 与深色星空 Hero、独角兽梦幻品牌高度契合 | 中 | **默认形态** |
| B. 彗星光带 | 一条渐变拖影光带沿轨迹衰减，尾部长而柔 | ★★ 优雅但偏"科技感"，与内容型站点略冲 | 中（需轨迹平滑） | 备选形态，参数化预留 |
| C. 纯色小圆点蛇形队列 | 固定 N 个圆点依次跟随（经典 CSS 蛇） | ★ 均匀呆板，无随机生命感 | 低 | 不采用（作为 DOM 方案对比保留在 §2） |

结论：**默认实现形态 A（星尘粒子）**，组件内以单一常量切换形态 A/B（B 作为后续可选皮肤，不在首期实现）。点击时触发一次小型"星芒迸发"作为可选彩蛋，列为 P2 增强。

## 2. 技术选型

| 方案 | 原理 | 性能 | 表现力 | 结论 |
|---|---|---|---|---|
| **Canvas 2D 全屏画布（推荐）** | 单个 `<canvas>` 覆盖视口，`requestAnimationFrame` 循环内绘制/更新粒子 | 优：一次绘制调用画 N 个粒子；配合预渲染光斑贴图，每帧成本极低 | 高：任意粒子物理、混合模式、形状 | **采用** |
| DOM + CSS（div 跟随） | 每个粒子一个 div，transform + transition/animation | 中：粒子数多时 DOM 数量与样式计算开销大，需节点回收 | 低：只能做规则圆点/图形，难做逐粒子物理与闪烁 | 不采用 |
| SVG | 每粒子一个 SVG 元素，SMIL/JS 驱动 | 差：节点开销高于 Canvas，动画能力弱 | 中 | 不采用 |
| WebGL / PixiJS | GPU 渲染 | 极优（万级粒子） | 极高 | 过度设计：需引入依赖（违反零依赖现状）、仅百级粒子需求用不上；CSP 与包体积均不划算 | 不采用 |

**结论：原生 Canvas 2D，零新增依赖。** 站点当前无任何渲染类依赖（Vite + Vue 3 + Tailwind），保持纯手写 ~150 行的独立组件。

## 3. 详细设计

### 3.1 组件与挂载

| 项 | 设计 |
|---|---|
| 新增文件 | `src/components/MouseTrail.vue`（自包含：模板仅一个 canvas，逻辑全部在内，不新建 store/composable） |
| 挂载位置 | `src/App.vue` 中 `<AiAssistant />` 之后追加 `<MouseTrail />`。位于 `<router-view>` 之外，**SPA 路由切换不重挂**，拖尾跨页面连续不闪烁 |
| 模板 | 单个 `<canvas aria-hidden="true">`，无其他 DOM |
| 样式 | `position: fixed; inset: 0; pointer-events: none; z-index: 45;` |
| z-index 决策 | 取 **45**：低于页头（z-50）与 AI 助手头像/对话框（z-50），拖尾划过时从其下方穿过，不直压导航与对话文字。注意页头未滚动时是**透明底**，加法混合的亮粒子仍可能在白字附近隐约透出——低透明度下可接受，验收含专项人工走查；不过关时可把常量调至 60（粒子越过一切）或下调 MAX_OPACITY，一行可改，默认取克制值 |
| 管理端隔离 | `admin/` 是独立应用、独立入口与构建，不引用主站 `src/`，天然无此组件。无需开关或条件判断 |

### 3.2 画布与视口

1. **尺寸**：画布铺满视口；`width/height` 乘以 `devicePixelRatio`（**上限 2**，4K 高 DPR 屏不做 3 倍绘制），CSS 尺寸 100%；`ctx.setTransform(dpr, 0, 0, dpr, 0, 0)` 后一律按 CSS 像素坐标绘制；
2. **自适应**：监听 `resize`（含浏览器缩放）重设画布尺寸，去抖 ~150ms；重设时清空现有粒子（避免坐标错位残留）；
3. **透明背景**：画布不清底为不透明色，每帧 `clearRect` 全清后重绘——叠在视频背景/轮播图上方时保持透明叠加；
4. **混合模式**：使用默认 `source-over` 标准混合。曾评估加法混合（`lighter`，深色底上更发光），但本站 Hero 是明亮的视频/海报——加法在亮底上会叠加裁剪至不可见（Edge 真机实测拖尾"消失"即此因）；饱和色粒子用标准混合才能在任意背景上保持可见，发光感由贴图自身的柔边渐变承担。

### 3.3 粒子系统（形态 A：星尘）

**事件模型（性能核心 + 输入甄别）**：监听 `pointermove`（`passive: true`），**仅当 `e.pointerType === 'mouse'` 时记录最新坐标**，且不在事件里生成粒子。不用 `mousemove` 的原因：混合设备（触屏笔记本）上 `(pointer: fine)` 判定为 true，但手指点按屏幕结束后浏览器会派发兼容性 mouse 事件（含触点坐标的一次 mousemove），会在触点凭空爆出一撮粒子；`pointerType` 反映"这一次输入"的真实来源，顺带把触控笔（pen）一并排除。粒子生成放在 rAF 帧循环内按路程触发，事件路径上零计算开销。

**dt 归一化（跨刷新率一致性）**：帧循环首行计算 `dt = min(now − last, 32)`，归一化为标准帧系数 `k = dt / 16.67`。**全部动力学参数（阻尼、上浮、寿命衰减、速度继承、闪烁相位）按"每标准帧"口径统一乘 k 施加**——60Hz / 120Hz / 144Hz 屏上消散速度、上浮幅度、闪烁频率完全一致，不会在高刷屏上变成 2 倍速。dt 上限 clamp 至 32ms 还顺带防止标签页恢复或卡顿后的粒子瞬移。

**每帧流程**：

1. 计算 dt 与标准帧系数 k（见上）；
2. 计算鼠标自上一帧的位移向量与速度；
3. **按路程均匀撒点（期望值 + 余量结转，v1.2 修正）**：`期望粒数 = 本帧路程 / SPAWN_DISTANCE × PARTICLES_PER_SPAWN`，与上帧结转的小数余量（carry）合并取整，沿线插值撒点，小数余量留给下帧。**禁用「攒够 SPAWN_DISTANCE 才撒」的阈值写法**——循环「停帧→事件重启→游标对齐」会把已行路程反复清零，造成生成饥饿（Edge 真机实测零生成即此因）。期望值写法在任意事件率/刷新率下密度均匀；单帧位移 100px 时约撒 8 粒，高速甩动时路程不被吞，密度沿线均匀（快速移动自然形成更长的尾巴）；
4. 遍历固定槽数组中的存活粒子更新：位置 += 速度 × k；速度 ×= 0.92^k（阻尼按指数施加，跨刷新率等效）；`vy −= 0.01 × k`（轻微上浮，星尘感）；寿命 −= dt；
5. 绘制：遍历存活粒子 `drawImage` 预渲染贴图（见下），透明度随寿命 easeOut 衰减，尺寸随寿命缩小；
6. 回收：寿命 ≤ 0 的粒子置 `alive = false`，槽位留待复用（槽位模型见 §3.4）。

**两类粒子（每批随机混合，比例约 7:3）**：

| 类型 | 视觉 | 行为 |
|---|---|---|
| 光斑（dot） | 柔边发光圆 | 随机方向小速度散射 + 阻尼，透明度线性衰减，尺寸 1.5–3.5px |
| 星芒（star） | 四角星形 | 同上，但附加 `sin` 闪烁（频率随机 6–12Hz）、随机旋转角速度、尺寸 4–8px、寿命略长 |

**贴图预渲染（避免每帧渐变计算）**：初始化时为每种颜色各预渲染一张"柔边光斑"离屏 canvas（径向渐变，中心不透明→边缘全透明），星芒一张白色贴图（绘制时用 `globalAlpha`+尺寸变化即可，不做逐帧渐变）。**不使用 `ctx.shadowBlur`**（逐帧代价极高）。共 6 张小贴图（≤ 32×32px），一次性开销可忽略。

**色彩**：从品牌渐变色板按权重随机——`#818cf8`（indigo-400）、`#a78bfa`（violet-400）、`#c084fc`（purple-400）为主，`#22d3ee`（cyan-400）、`#f0abfc`（fuchsia-300）点缀——与首页 Hero 标题的 `gradient-flow` 动画同一色彩语言。

### 3.4 生命周期与性能预算

| 机制 | 设计 |
|---|---|
| rAF 启停 | **惰性循环**：`pointermove`（mouse）时若循环未运行则启动；帧循环内当"无存活粒子且鼠标静止"时，**先对画布做一次全量 `clearRect`，再 `cancelAnimationFrame` 并置运行态为 false**——停帧时画布必须已干净，防止"取消 rAF 但画布残留冻结粒子"的 bug。空闲时 CPU 占用为 0 |
| 页面隐藏 | `visibilitychange` → hidden 时停帧（cancel rAF），恢复可见后若有存活粒子则重启循环；dt clamp（32ms）保证恢复后不瞬移。绝不出现后台标签页烧 CPU |
| 粒子上限 | 固定 **160** 槽；全部占用时新生成粒子**复用最老存活槽**（环形游标覆盖）。上限即硬顶，保证最坏情况（画圈甩动）帧耗时可控 |
| 槽位模型（零分配） | **预分配 160 个粒子对象 + `alive` 标志，每帧全量遍历**（160 次布尔判定成本可忽略，代码比空闲链表更短）：生成时激活槽位、消亡时置 `alive = false` 归还槽位，稳态运行**零对象分配**，兑现 GC 承诺。（备选实现为"对象池 + 空闲链表"，收益相同、代码更长，不采用） |
| 指针离窗 | `pointerleave`（document 级）置鼠标为非活动，停止生成；存量粒子自然消散后循环自停（自停前同样先清画布） |
| 内存 | 画布随视口而定；6 张预渲染贴图 + 160 槽固定数组，全部在启动时一次性分配；无定时器泄漏（组件卸载时移除全部监听并 cancel rAF） |

**性能预算验收线**：移动鼠标时单帧 rAF 回调耗时 ≤ 2ms（DevTools Performance 面板，无明显长任务）；持续画圈 5 分钟，堆内存曲线平稳无阶梯式增长。

### 3.5 环境适配与降级（分寸设计）

| 环境 | 行为 | 检测方式 |
|---|---|---|
| `prefers-reduced-motion: reduce` | **完全禁用**：不创建动画循环、不挂 pointermove、canvas 不渲染（与站点既有约定一致——`HeroCarousel`/`BackgroundVideo` 已按此适配，《前端主站优化方案》F-20 会进一步全局加固） | `matchMedia('(prefers-reduced-motion: reduce)')`，组件 setup 时一次性判定 |
| 触屏设备 / 纯平板 | **完全禁用**：触屏没有 hover 悬停语义，拖尾跟随手指反而干扰滚动 | `matchMedia('(pointer: fine)')` 为 false 时不绑定任何监听（组件近乎零成本存在）。注意该媒体查询判定的是"**主指针**"，作为整机开关够用，但反映不了混合设备上"当次输入"的来源，见下一条 |
| 触屏笔记本等混合设备（pointer: fine 命中） | 正常启用，但**只跟随真实鼠标**：手指点按屏幕结束后浏览器会派发兼容性 mouse 事件（含触点坐标），若不过滤会在触点凭空爆出一撮粒子；触摸滚动不受影响 | `e.pointerType === 'mouse'`（当次输入的真实来源），触控笔（pen）一并排除 |
| 低电量/省流（`saveData`） | 不做处理：该效果无网络流量，CPU 开销已被惰性循环约束到"仅移动时" | — |
| 手动开关 | 可选：`localStorage['mouse-trail'] === 'off'` 时禁用，供个别用户自行关闭（无 UI 入口，键盘党/极简党可用控制台设置；是否实现由实施者定，10 行内） | — |
| 旧浏览器 | Canvas 2D + rAF + matchMedia 均为 baseline 能力，无需降级分支 | — |

### 3.6 与现有功能的兼容性核查（逐项）

| 现有功能 | 影响 | 结论 |
|---|---|---|
| AI 助手头像拖拽（`AiAvatar` document 级 mousemove 拖动） | 拖尾仅读坐标+绘制，不改任何事件流；`pointer-events: none` 不截获事件 | 无冲突。拖动头像时会带出星尘——视觉上反而契合"梦幻"设定，可接受 |
| AI 对话框（z-50）可读性 | 拖尾 z-45 在其下方，粒子划过被面板遮挡 | 无干扰 |
| 固定页头（z-50，含 backdrop-blur） | 同上，拖尾从其下方穿过 | 无干扰 |
| 首页背景视频 / 学习页固定视频 | 画布透明叠加，加法混合在视频亮部会略微增亮，属自然效果 | 无干扰 |
| 文本选择、表单输入、悬停态 | pointer-events: none | 无干扰 |
| 路由切换 | 组件在 `<router-view>` 外，不随页面重挂，无闪烁 | 无影响 |
| CSP（Node 层 `script-src 'self'`） | 组件经 Vite 打包为外部脚本，无内联脚本/样式 | 无冲突 |
| 构建产物 | 产物由 `vite build` 生成，新组件自动纳入。`scripts/build-deploy.js:9` 当前实际拷贝 `['server', 'scripts', 'src']`（`src` 随《前端主站优化方案》F-22 移除，属"源码不进部署包"的清理项，与本组件无关）；预计包体积增量 < 4KB（gzip） | 无构建改动 |
| `admin/` 后台 | 独立应用 | 天然隔离 |

### 3.7 参数默认值（实施时以此表为准，全部收拢为组件顶部常量）

| 参数 | 默认值 | 说明 |
|---|---|---|
| DT_NORM | dt = min(now − last, 32)；k = dt / 16.67 | 全表"标准帧"口径参数统一乘 k 施加；clamp 防标签页恢复后粒子瞬移 |
| SPAWN_DISTANCE | 18px | 密度常数：期望粒数 = 帧内路程/该值 × 每批粒数（见 §3.3） |
| PARTICLES_PER_SPAWN | 3 | 每批粒子数（光斑:星芒 ≈ 7:3 随机） |
| MAX_PARTICLES | 220 | 固定槽数；占满后环形游标覆盖最老存活槽 |
| LIFETIME | 900ms ± 300ms | 星芒取长半区（约 1000–1400ms）；按 dt 递减 |
| SIZE_DOT / SIZE_STAR | 2.5–5px / 6–12px | 半径/外接尺寸 |
| VELOCITY_INHERIT | 30% | 继承鼠标速度（甩得快尾巴甩得远） |
| INITIAL_JITTER | 0.2–0.8 px/标准帧 | 随机初速方向与大小（施加时 ×k） |

## 6. 风险与备选

1. **视觉干扰风险**（最大风险是"炫但烦"）：以低透明度（≤0.85 起步快速衰减）、短寿命（≤1.2s）、克制密度为硬约束；实施时先按默认参数上线，观感由使用者确认后再调；
2. **低端设备风险**：惰性 rAF + 160 粒子上限 + 预渲染贴图已封顶最坏情况；如仍有低端机反馈，可将 `PARTICLES_PER_SPAWN` 降为 1 或直接手动开关关闭；
3. **形态扩展**：彗星光带（形态 B）留作后续皮肤，通过组件内形态常量切换，不动架构；
4. **回滚**：删除 `App.vue` 中一行挂载即可整体下线，零残留。
